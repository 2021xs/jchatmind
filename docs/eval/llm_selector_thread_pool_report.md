## 参数选择解释

- 推荐参数 `4/4/6` 在正常峰值下 24 个请求中 fallback=0、timeout=0、429=0，P95=9988ms。
- `4/4/4` 在连续峰值批次中 reject=2，说明运行容量与名义峰值完全相等时缺少任务交接余量。
- 12 并发过载时，`4/4/6` reject=2、P95=9390ms；`4/4/8` reject=0、P95=11648ms。较小队列通过现有 fallback 提供明确的上游保护。
- `8/8/0` P95=4653ms，但最大 LLM 并发为 8；推荐参数最大 LLM 并发为 4 且已经满足验收线，因此不扩大外部并发。

## 自动验收规则

正常峰值场景必须同时满足：fallback=0、timeout=0、429=0、JSON解析成功率=100%、最大线程数≥峰值并发的一半（最多两波执行）、P95≤timeout/2=15000ms。满足规则后优先选择更小的最大线程数，再选择更小的队列。
